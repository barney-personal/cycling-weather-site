Forward History Method

Methodology

How the daily ranking is built and how predictions are graded against reality.

Forecast pipeline

  • Every day at 04:15 UTC a Python job pulls a 14-day forecast for 22 destinations from Open-Meteo (with wttr.in as fallback).
  • Each daily forecast row is graded as ride-clean if all of: max temp > 25°C, precipitation 0 mm, max precip probability < 10%, weather code in {0,1,2,3} (clear → partly cloudy), max wind < 30 km/h.
  • Each destination's score = best_run × 100 + dry_days × 5 + median_high. A destination is a qualifier if its longest clean run ≥ 7 consecutive days (UK destinations also need median high > 20°C).
  • The full structured snapshot (per-day arrays per destination) is persisted to data/cycling/forecasts/YYYY-MM-DD.json.

Actuals pipeline

  • A second daily job pulls the Open-Meteo Historical Archive for any forecast date now ≥ 2 days in the past (the archive trails real-time by ~1–2 days).
  • Persisted to data/cycling/actuals/YYYY-MM-DD.json. Idempotent — re-runs only fill gaps.
  • Actuals use a simplified ride-clean rule (no precip-probability series): max temp > 25°C, precipitation 0 mm, weather code in {0,1,2,3}, max wind < 30 km/h.

Predictions vs reality

  • For every (snapshot, target-date) pair where actuals exist, we record predicted and actual temp/precip/qualify and the lead time in days.
  • Hit rate = of all days predicted ride-clean, what fraction were actually ride-clean. Bucketed by 1–3 / 4–7 / 8–14 day lead.
  • Mean temp error = mean absolute difference between predicted and actual daily high.
  • Calibration view will populate as more snapshots mature; today the site is seeded with 30 days of actuals and zero matured forecasts.

Caveats

  • Single grid-point per destination — local microclimates not captured.
  • Open-Meteo daily aggregates use the location's local timezone; we don't normalise across hemispheres.
  • Wind threshold is a simple max-gust style rule; it doesn't differentiate headwind vs tailwind.
  • The qualifier rule is a hard binary; close-misses (e.g. 6-day clean runs) aren't surfaced.
Sources: Open-Meteo · Open-Meteo Historical Archive · wttr.in
